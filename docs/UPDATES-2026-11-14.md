# 2026-11-14 引导修复与验证

本次公开源码，不包含可直接刷入的完整手机 boot 镜像。已有 v0.1.0 预览附件不是本次修复固件。不要混用版本。

## 已有实机结果

- Mi8 菜单进入 FASTBOOT、TWRP：已分别观察到原厂 FASTBOOT 画面及 TWRP。
- 菜单关机：直接 PS_HOLD 路径，拔线执行后观察30秒没有重新启动。
- 关机插线：充电启动检测转交原 Android 路径，观察到电池/充电画面。
- ST FTS FTM5 触屏：卡片选择、滑动、高级页和两层返回通过。只借用空闲活动 TCS 组，保留原配置；不刷触控固件。
- 手势取消：移出松手、移出再移回松手取消；新的轻点正常；按键路径保留。
- 首页和高级页提示统一为“触屏或按键操作”。字体子集必须覆盖当前源码全部汉字，否则会混用回退字体。
- 隐藏 Boot flags / FTS 可见诊断标签；诊断协议保留。

## 重要启动回归与未完成事项

充电识别整合曾遗漏双启动 BootShim 的 XNUP 复制步骤，导致 no payload。现已恢复并加入长度上限，实际 ARM64/QEMU 验证正常复制及坏标记、过小、超长拒绝；临时版本随后进入过 iOS 桌面。

正式安装版本与临时版本没有完成统一。最近仍出现内核跳转后停住的画面，当前不能宣称正式版本稳定启动 iOS。必须从备份、临时启动、双系统交接验证重新走完整流程，再考虑永久写入。

1920→1984MiB 内存盘仅为实验，双存档槽仍各2GiB。两款大型应用装入后估计仅余约38MiB（未扣部分元数据），不足以宣称可日常使用；游戏图标和启动尚未验证。新归档头 slot 必须与物理目标槽一致，并同时校验头/内容 CRC。不要通过修改容量显示假装扩容；没有实现 Android/iOS 平分128GB。

扬声器与音量曾实机可用；蓝牙发现/配对可用，蓝牙耳机声音、麦克风、通话和相机不属于本次已修复范围。iOS 滑动关机卡圈与引导菜单关机是两个问题。

## 集成

FTS 源码位于本目录适配树，对应 INF 加入 dipper DSC/FDF，并将 HerculesFtsProbe.h 放入 QcomPkg Include/Protocol。启用 ENABLE_UEFI 后使用本仓库的触屏桥接。正式版本不定义 HERCULES_FTS_TRACE_DIAGNOSTIC、HERCULES_CHARGER_TRACE_DIAGNOSTIC、HERCULES_RAM_NO_COUNTDOWN；保留默认10秒 Android 选择，首次输入取消本轮计时。

BootShim 使用同目录 charger_probe.c 和 HerculesCharger.ld 联编；先验证 Android 分支、充电检测、XNUP 拷贝与内存边界，再制作设备专用 boot。PMIC、TLMM、I2C、TCS、IMEM、PS_HOLD 地址都是 dipper 特定，禁止直接复制到其他型号。

本机 UI 字体源为 Windows 微软雅黑，未确认再分发授权，未作为开源字体发布。使用 tools/make_local_font_pack.py 从自行具备使用权的字体生成；原 SVG 保留。禁止上传系统镜像、私有功放固件、IPA、存档、原始设备日志或用户对代理的私人指令。
