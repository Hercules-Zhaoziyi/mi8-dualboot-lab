# 使用说明

## 首页

开机进入菜单后默认选择 Android，并显示 10 秒倒计时。未操作时启动 Android；任意按键或触控会取消本次开机计时。取消后可以一直停留菜单，进入高级选项再返回也不会恢复计时。

音量上/下移动选项，短按电源执行。系统卡片上的蓝框和勾选代表当前系统选择；触控点卡片只选择，点底部启动按钮执行。焦点移动到高级选项时，系统勾选和蓝框清除，底部按钮变为「高级选项」。

菜单倒计时只控制启动选择，不给 iOS 内核运行设置时长上限。

## 高级选项与子菜单

使用与首页一致的壁纸、玻璃卡片、字体和页脚。维护入口来自运行时已有的 `boot_config`，常见项目包括 UEFI Shell、继续固件引导、系统维护工具、UEFI 启动管理、重启与关机。

进入页面后默认聚焦返回按钮，短按电源即可返回。子菜单返回上一级；根高级页返回首页并恢复之前的系统选择。功能入口是否出现取决于宿主固件探测结果。

## 数据与关机

iOS 用户数据仍使用上游的内存数据卷和双槽存档机制。周期保存不是瞬时完成，强制重启可能丢失最近尚未成功存档的修改。本机大存档有序保存实测可耗时约一分钟以上。

iOS 滑动关机卡圈仍是已知问题；本仓库的菜单工作不等于解决该问题。需要可靠结束设备时，可按已验证的本机流程进入 Android 或 TWRP 正常关机。

## 字体资源缺失

公开组件需要在本机准备并集成同款字库资源。若看到 `Local UI font pack required`，先按 [FONTS](FONTS.md) 完成资源准备；这时不会用其他字形冒充定稿界面，也不会自动倒计时启动。
