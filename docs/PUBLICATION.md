# 公开范围与附件

## 收录

实际 UI 源码、对应 SimpleInit 及库源码、引导交接源码、构建与检查工具、中文说明、设计稿/渲染图、用户指定 SVG 原件，以及经过隐私审查的设备照片。每个附件的处理结果见 `attachments/manifest.json`。

SVG 原件逐字节复制，不更换标志；固件副本仅归一化视口尺寸，图形路径和颜色保留。渲染图和设计稿分开标记，不冒充实机截图。

## 不上传

- IPSW、XNU/内核二进制、iOS root/APFS/cryptex、Apple 私有组件及包含它们的完整 boot 镜像。
- 第三方应用 IPA、SDK、平台专有固件、Microsoft 字库和本地字体包。
- 手机原始数据分区、用户存档、keychain、账号/授权 URL、密钥、令牌、签名材料。
- 含设备序列号、MAC、网络配置或其他敏感内容的原始附件与日志。
- 原始模型内部过程、工具会话、私人维护交接和机器路径。

设备照片会去除非必要 EXIF/XMP 等元数据，保留压缩像素与必要的方向信息。涉及身份或网络信息的图不靠伪造画面隐藏，而是明确排除。不能获取的早期临时附件在清单说明，不声称已经上传。

## 固件范围

Release 是 UI 应用/FFS 与交接组件，不是完整手机系统包。对应源码及依赖固定版本、第三方许可证、构建记录和 SHA256 一并提供。法律归属声明中会保留开源依赖要求的版权通知；这些通知不代表仓库包含 Apple 专有系统材料或取得 iOS 整包分发授权。

发布后不自动更新维护者的手机，也不上传此前的私人整合镜像。所有本地私有输入均由 `.gitignore` 和审查脚本排除。
