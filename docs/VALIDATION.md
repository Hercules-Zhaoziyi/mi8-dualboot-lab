# 验证记录

## 实验设备

小米 8 `dipper`，8 GB RAM / 128 GB 闪存，原系统 MIUI 12.5.2、Android 10；Windows 11 主机与 WSL Ubuntu 构建。设备序列号、MAC、分区唯一 GUID、私人路径及原始应用日志不公开。

## UI 主机回归

实际执行 LVGL、FreeType 和 NanoSVG，使用 ASAN 检查对象及字库生命周期。测试 SVG 解码与固件一致：固定 2 倍采样，不用旧的 1 倍假设。

- Android、Apple、小红书的布局盒固定为目标尺寸，内部包含式缩放；系统标志不覆盖标题。
- 高级选项清除两张系统卡片的勾选和蓝框，底部动作正确路由；返回恢复原系统选择。
- 原生文字与两页署名节点检查。
- 按键、触控、12 次页面往返、重启/UEFI 子菜单返回、重复事件保护。
- 无输入 10 秒只启动 Android 一次。
- 导航键、任意键、触控取消本次开机计时；等待超时及高级返回后不恢复。
- 公开资源模式在提供本机同款字体时保留同一 UI；缺少字体时进入手动提示、不替换字形、不自动启动。

## 设备证据

维护者实际执行了临时完整菜单启动，确认图标、焦点、返回、iOS、旧截图和两个应用正常。Android 入口通过 ADB 核对机型、开机完成、原 MIUI 版本与桌面进程。无主机菜单输入的临时启动随后读取到新一轮 Android 开机完成。

正式安装前，最新有效数据归档完整头部/内容 CRC 和记录边界通过，包含照片与两个应用。仅写 boot，候选全长回读一致；TWRP、主副 GPT 前后一致。维护者随后报告测试正常。

正式重启后的某次 ADB 检查未读到 Android 完成，之后维护者报告测试无问题；不把这次未取得的主机证据写成通过。也不凭泛化确认声称独立测过所有冷启动时序。

## 公开组件与手机安装版的差别

UI 代码、SVG 和界面基准保留。公开组件把同款字体改为本机提供的 RAW FFS 资源，移除字库软件分发；这是新增资源供给封装，已经模块构建和主机回归，未再次刷机验证。Release 标为实验性组件。

主机截图是实际控件渲染；设计稿另有标签，不作为设备成功证据。所有限制见 [STATUS](STATUS.md)。
