# 功能状态与限制

更新：2026-11-12。

| 项目 | 观察结果 | 边界 |
| --- | --- | --- |
| Android / iOS 菜单 | 本机整合版实机进入两个系统，正式 boot 回读一致 | 公开外部字库封装另有主机测试，未重新刷机 |
| 原生界面 | 标题、版本、提示、按钮和署名为文字控件；指定 SVG 保留 | 固件 2 倍 SVG 采样需显式目标尺寸 |
| 高级选项 | 统一第二页、子菜单、返回和单独选中 | 可用入口随宿主探测变化 |
| 10 秒自动选择 | 主机计时回归通过，临时启动进入 Android | 首次输入取消，本次开机不重启计时 |
| iOS 设置/照片/应用 | 用户确认重启保留、两个测试应用可进入首页或登录页、截图可保存 | 不等于所有应用功能和数据库完整性已回归 |
| Wi-Fi / Safari | 用户确认新网页打开、刷新 | 已验证 WPA2-Personal 组合；不代表 WPA3、企业认证等均支持 |
| 蓝牙 | 搜索、配对、连接耳机通过 | 没有声音，音频子系统未支持 |
| 显示/触控/亮度等 | 上游及本机短时实验已有可用结果 | 不是完整长期外设回归 |

## 尚未实现

- iOS 直接使用数十 GB 闪存的可写数据后端，以及 Android/iOS 各约一半的数据迁移。
- iOS 滑动关机最终卡圈的修复。
- 可靠断电时钟；当前移植仍有构建时刻回退。
- 相机、电话、移动数据、完整音频/蓝牙耳机声音等未覆盖功能。
- 设备名称修改还原的原因和修复。
- Apple 标准 USB 管理传输；当前调试接口不能直接替代爱思/iTunes 所需协议。

降低渲染分辨率等上游可选优化不能当成默认稳定配置；本机默认保持原生分辨率。上游的最新边界应同时查阅 [dipper-xnu](https://github.com/youzjuzi/dipper-xnu)。


## Agent 复刻与通用源码扩展

新增固定上游复刻入口、阶段验收、Mi8 双启动汇编和本地组合打包实现；菜单目标/版本文字可配置，解除固定 GOP 尺寸限制。默认 Mi8 UI ASAN 回归及 AArch64 模块构建通过；profile 的缺失 GUID 拒绝和生成 header 语法检查通过。其他分辨率视觉、其他手机硬件与新组合脚本端到端仍未测。v0.1.0 Release 未替换；新源码不作为全机型可刷固件宣传。详见 AGENT-PORTING-RESULTS.json。
