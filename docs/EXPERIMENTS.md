# 网络、蓝牙与应用实验

## Wi-Fi

早期存在可加入热点但 Safari 无法访问外网、部分正常网络无法加入的情况。同步与诊断后，维护者确认小米 8 的 iOS Safari 能打开新网页并刷新。没有将该结果归因于一个未隔离验证的参数。

实际可连接的 WPA2-Personal/AES-CCMP 组合不代表 WPA3、企业认证、TKIP 或强制 PMF 均支持。热点本身也应由另一设备确认可上网。公开截图不暴露实际网络名、MAC 或 IP 配置。

## 蓝牙

同步蓝牙上游后，维护者验证搜索、配对和显示连接；耳机没有声音，与音频子系统未移植的边界一致。不能把“已连接”写成音频可用。原机提取的蓝牙/GPU 固件不重新分发。

## 应用

用户提供了两个未加密的测试 IPA，在本机完成代码页签名核验、容器/桌面注册和跨重启基本启动。曾因 ZIP 中文件执行位不正确而启动失败，修复 Mach-O 文件执行权限后能进入首页或登录页。此结果不代表全部功能、登录、推送或音视频均可用。

IPA、注入的第三方库、账号、签名私钥和应用数据不上传。用户应自行准备有权使用的应用。不能把加密 IPA 仅改标志或重签当成已经解密。

## 爱思助手

电脑端未识别的原因不等于 Windows Apple 驱动损坏：当前实验接口提供自定义调试通道，未实现标准 Apple USB 管理协议。安装官方客户端不自动补齐设备端协议。官方移动端资源中观察到加密代码，未当成普通重签包安装，也不在仓库分发。
