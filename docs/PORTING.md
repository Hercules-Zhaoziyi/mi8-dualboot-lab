# 跨机型引导适配

通用的是 UI 源码、资料结构与 agent 工作流，不是一个能够直接刷入所有手机的二进制。当前发布的旧 EFI/FFS 仍是 Mi8 构建；本节新增的通用适配代码需要重新构建。其他机型没有实机验证，也没有因此获得 iOS 支持。

## 分层适配契约

| 层 | 要提供的实现 | 可复用部分 |
|---|---|---|
| OEM 启动链 | 解锁能力、boot 格式/签名、DTB/DTBO、AVB、槽位与回退 | 证据与备份流程 |
| 平台 UEFI | CPU/内存图、异常级、缓存、时钟、GOP/面板、输入、存储、ResetSystem | 兼容的 EDK2/SimpleInit 库 |
| 目标启动适配器 | Android 内核交接、Linux/其他 EFI 入口、可选 iOS loader | UI 的 boot_config 路由 |
| UI | 分辨率、DPI、安全区、键值/触控映射、目标 GUID、版本文字、字库 | 本仓库原生控件、SVG、倒计时、高级页 |
| iOS 平台移植 | XNU/设备树、MMU/IOMMU、中断、定时器、UFS、显示/GPU、输入及外设 | 有条件借鉴上游；不是 UI 移植的一部分 |

优先找该机型已有、可构建和恢复的 UEFI port。即使同为骁龙 845，面板、内存保留区、触控、存储 LUN、固件和校准也可能不同。未具备内核/驱动支持的设备，应先完成 Android/另一个已有 EFI 系统的菜单验证，将 iOS 记录为 blocked，而不是伪造一个可启动入口。

## 配置与代码入口

复制 `profiles/other-device.template.json` 到 `local/target.json`，填入自己的两个真实 EFI 目标 GUID 和系统标签，然后执行：

```bash
python3 tools/generate_target_profile.py local/target.json --out local/generated-target
```

生成 `hercules_target.h`、`simpleinit.static.uefi.cfg` 与本地集成提示；不会写入手机或修改源码。将 header 作为该目标构建的 `bootmenu_hercules.inc` 同目录输入（先备份），配置作为该宿主固件卷的配置资源。默认 header 保留 Mi8 文字与行为。另一个系统不必是 iOS；使用 Linux 等系统时同时替换对应图形资产与归属，不能用 Apple 图标暗示 iOS 已可用。模板 GUID 是空值，未填真实入口会拒绝生成。

源码已移除仅接受 1080×2248 的门槛，按 GOP 实际宽高缩放布局，壁纸覆盖裁切；字形尺寸随宽度计算。默认 1080×2248 保留原样。极端宽高比、横屏、刘海/圆角安全区仍需单独设计与回归，不能把等比缩放当成完整响应式认证。安全区应通过调整 `hercules_x/y`、页脚及卡片矩形落实，而不是画一个假刘海。NanoSVG 2 倍采样契约须与固定容器/缩放一起保留。

## 硬件适配清单

1. 用只读库存确认 SoC/板级版本、真实内存图、启动槽、分区布局、GOP 分辨率/stride/像素格式。
2. 单独验证 UEFI 图形、物理按键和触控；映射为 LVGL 输入事件。无输入的菜单倒计时不能作为刷错平台的逃生机制。
3. 保留可恢复的原厂启动链，先用该设备支持的临时启动方式运行菜单；不支持 fastboot boot 的机型不能假装该命令可用。
4. 实现并审查目标自己的启动交接。Mi8 的 `Reboot2PayloadApp.c` 向特定物理地址写 magic 后 warm reset，只能用于匹配 BootShim；其他设备必须替换，不能只改产品名。
5. 设置 UEFI DSC 的平台库、GOP/DPI PCD 和包路径；不能直接拿 Xiaomi/sdm845 DSC 去构建其他 SoC。
6. 加载本地合法字库，测试中文、版本文字、原 SVG、焦点/勾选、菜单返回、首次输入取消倒计时；分别验证两个真实目标。
7. 通过完整镜像结构/容量检查、RAM 测试、备份回读和 owner 授权后才正式安装。每个型号单独保存机型、固件、源码 commit、构建摘要和验收记录。

## 验证矩阵

当前 Mi8 默认 UI 的主机测试不变；新的通用缩放与 profile 工具属于开发版。其他手机仍为未验证。要求新 port 至少覆盖：小/原生/大分辨率，GOP stride 与颜色，安全区，音量/电源/触控，长按与重复事件，10 秒无输入、首键取消及高级返回不恢复，字体缺失，两个目标真实启动，恢复入口及断线冷启动。只提交脱敏结论和开源代码，不提交校准、系统镜像或设备存档。
